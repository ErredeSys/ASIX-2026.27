if ($port -eq 443) {

## 2. if o switch

Crea:

```
$estat = 2
```

Fes que el programa mostri:

```
1 → Iniciant
2 → Executant
3 → Finalitzat
4 → En espera
qualsevol altre valor → Estat desconegut
```

> Problema utilitzant if:

```
$estat = 2

if ($estat -eq 1) {
    Write-Host "Iniciant"
}
if ($estat -eq 2) {
    Write-Host "Executant"
}
if ($estat -eq 3) {
    Write-Host "Finalitzat"
}
if ($estat -eq 4) {
    Write-Host "En espera"
}
else {
    Write-Host "Estat desconegut"
}
```

> Problema utilitzant switch:

```
switch ($estat) {
    1 { "Iniciant" }
    2 { "Executant" }
    3 { "Finalitzat" }
    4 { "En espera" }
    default { "Estat desconegut" }
}
```

Resol el problema utilitzant `if` i `switch`. Compara les dues solucions.

> La diferència entre les dues solucions es que if es molt mès repetitiu i triga més ja que va comprovant progressivament if per if i en el cas del switch, es veu molt mes clares les opcions i esta pensat per seleccionar varis casos. Es mes fàcil d'interpretar el switch i en aquest cas amb varies opcions, penso que es molt millor que utilitzar l'if que funcionaria millor amb menys condicions (1 o 2).

## 4. Condicions combinades

Crea:

```powershell
$port = 443
$actiu = $true
```

Mostra:

```text
Servei disponible
```

només quan el port sigui el 443 i estigui actiu

> He utilitzat -and per combinar les dues condicions i m'ha mostrat el text. Si una de les dos no fos correcte, utilitzant aquest codi no mostraria res.

```
if ($port -eq 443 -and $actiu -eq $true){Write-Host "Servei disponible"}
```

## 7. Objectes

Quants serveis en el teu sistema estan configurats amb el servei d'arrencada automàtic quan s'inicia l'equip?

Proposa diferents codis de resolució.

> 1r Proposta: Mostrar els serveis d'arrencada automàtic i contar-los manualment

```
Get-Service | Where-Object { $_.StartType -eq 'Automatic' }
```

> 2n Proposta: La mateixa comanda i afegir Measure-Object per contar els serveis.

```
Get-Service | Where-Object { $_.StartType -eq 'Automatic' } | Measure-Object
```

> 3r Proposta: Utilitzar una variable per guardar el .count de la condició i després executar-la.

```
$arrencadaAutomatic = (Get-Service | Where-Object { $_.StartType -eq 'Automatic' }).count
$arrencadaAutomatic
```

# Conclusions

Explica amb les teves paraules:

1. Què representa la variable `$servei` en:

```powershell
$serveis = Get-Service
foreach ($servei in $serveis) {
    ...
}
```

> $servei representa cada objecte que està dins $serveis. Si hi ha 50 objectes, el bucle s'executarà 50 vegades.

2. Quina diferència hi ha entre `foreach` i `ForEach-Object`?

> El foreach és un bucle "tradicional" més ràpid i s'utilitza quan ja tens una variable creada amb dades, a diferència del ForEach-Object que s'utilitza dins del propi pipeline, és mes lent i s'utilitza mentres es processa les dades del pipeline.

3. Què representa `$_` dins de `ForEach-Object`?

> $\_ és l'objecte actual del pipeline, bàsicament es refereix al servei.
